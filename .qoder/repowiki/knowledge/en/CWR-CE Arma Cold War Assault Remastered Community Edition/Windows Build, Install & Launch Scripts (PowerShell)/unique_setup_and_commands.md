Requires `VCPKG_ROOT` to point at a vcpkg checkout (fallback `C:\dev\vcpkg` is auto-detected) and LLVM installed at `C:\Program Files\LLVM\bin` so clang-format/clang-tidy are discoverable. Typical workflow: run `scripts\Build.ps1` (default preset `win-x64-clang-rwdi`), then `scripts\Install.ps1` once to copy Demo assets into the retail install, then `scripts\Start.ps1` to launch. Extra engine flags pass through via position 0 (`ValueFromRemainingArguments`).
