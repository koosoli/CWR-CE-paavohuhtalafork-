Flat vendor layout under `thirdparty/` containing two independent third-party packages with no internal cross-dependencies: `glad/` provides a generated OpenGL 4.5 Core loader split into `include/glad/gl.h` (C/C++ header with platform macros and function prototypes) and `src/gl.c` (implementation compiled once), plus the KHR platform header; `renderdoc/renderdoc_app.h` is a single MIT-licensed header exposing RenderDoc's in-application capture API. The directory contains no build files — these vendored sources are consumed directly by the parent project's build system, while other dependencies (catch2, cli11, stb, mimalloc, freetype, sdl3, openal-soft, opus, enkits, imgui, spdlog) are resolved externally via vcpkg as documented in `README.md`.
