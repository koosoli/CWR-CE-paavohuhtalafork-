Configure with `cmake --preset win-x64-clang-rwdi` or `linux-x64-clang-rwdi`, then `cmake --build build/<preset>`. Run unit tests via `ctest --test-dir build/<preset>`. Integration tests require building `cargo build -p tri`, copying `.trident.env.example` to `.trident.env`, and running `./target/debug/tri test -j6 --retries 2 tests/integration`. Lint/format targets are `Format`/`FormatFix`, `Tidy`/`TidyFix`, `PythonLint`/`PythonLintFix`, and combined `Lint`/`LintFix`.
