Local development uses `cmake --preset <name>` where `<name>` comes from `cmake/presets/{linux,windows}.json` (e.g. `linux-x64-clang`, `win-x64-clang-dbg`). The SteamRT4 container is built with `docker build -f docker/steamrt4/Dockerfile docker/steamrt4` and invoked as `docker run -v $(pwd):/work/ofpr -e OFPR_PRESET=linux-x64-steamrt4 steamrt4-image`, which calls `run-build.sh` to configure, build, and optionally copy the `tri` Rust binary into `dist/<preset>/`. The papa-bear service is built via `docker build -f docker/papa-bear-master-service/Dockerfile mserver` from the `mserver/` context.
