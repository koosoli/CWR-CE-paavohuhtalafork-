The module is split into two orthogonal concerns:

- `cmake/` — CMake configuration layer. `presets/base.json` defines a shared Ninja + vcpkg + ccache baseline; `presets/linux.json` and `presets/windows.json` extend it per platform with concrete `linux-x64-clang`, `steamrt4-*`, and `win-x64-clang-*` presets. Each preset chains a vcpkg triplet from `vcpkg-triplets/` (e.g. `x64-linux-clang.cmake`) which sets architecture, CRT linkage, and `VCPKG_CHAINLOAD_TOOLCHAIN_FILE` pointing to the matching file under `toolchains/` (e.g. `linux-x64-clang.cmake`, `win-x64-clang.cmake`). Toolchain files set compilers, flags, and call `FindLLVMSanitizer.cmake` to locate LLVM tools. `vcpkg-overlay-ports/openal-soft/` provides a custom portfile that patches kcat/openal-soft via `.diff`/`.patch` files and toggles backends by target OS.
- Helper CMake scripts at the top level (`GenerateBuildInfo.cmake`, `CatchAddWindowsSafeTests.cmake`, `TridentCTest.cmake`, `CheckFileSize.cmake`, `CopyIfExists.cmake`, `DistCopy.cmake`, `RunTridentCTest.cmake`, `static-crt-flags-override.cmake`) are included by the root `CMakeLists.txt` to generate `BuildConfig.h.in`-style headers, run tests, and package artifacts.
- `docker/` — Two independent container definitions: `papa-bear-master-service/Dockerfile` builds a Rust binary in a `rust:1-bookworm` stage and ships it in a distroless nonroot image; `steamrt4/Dockerfile` provisions a SteamRT4 SDK image with vcpkg seeded at `/opt/vcpkg-seed` and exposes `run-build.sh` as `/usr/local/bin/steamrt-build`, which orchestrates the CMake+vcpkg+ccache build pipeline using environment variables like `OFPR_PRESET`, `OFPR_TARGETS`, `OFPR_SKIP_CARGO`, and `OFPR_VERSION_TAG`.
